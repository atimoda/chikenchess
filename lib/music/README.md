# Strudel music engine and Creative lab

All 13 registered cities (14 stages, because Manchester has two eras) and Creative use `@strudel/web` 1.3.0. The existing native engine continues to provide introductory/UI/end-game sound effects; its loop compilation and playback are disabled for these stages.

For task-oriented navigation, start with `docs/CODEBASE_MAP.md` and `tests/README.md`.

## Try it

Run `npm install` and `npm run dev`, then open `/?city=dusseldorf` on the printed local URL. Complete the existing introduction.

For immediate experiments, open `/creative`, choose a factory or saved kit and press **Carregar kit**. Current-revision saved city kits take priority over composed factory arrangements. The first load after a catalog revision backs up the previous city kit for recovery. The 16 white voices are active in Creative; gameplay activation still comes from moves and the temporary check overlay. **Salvar kit** stores the edited kit in this browser and can link it to one city at a time. Export JSON to transfer kits between devices; there is no shared database yet.

- Hold/drag a piece to play individual notes before making a move. Its loop is suspended during the gesture; entering a new square triggers one attack. Holding still does not repeat the phrase. Solo auditions the complete pattern; the redundant hold-to-listen button was removed.
- Release on an illegal destination, the original square, or outside the board to cancel. Escape, touch cancellation, and window blur also end the audition.
- Complete a legal move to activate that piece's pattern. AI pieces activate on their moves too. Captured pieces are removed from playback.
- Check temporarily activates all surviving attacker pieces and bypasses their entry masks. Resolving check restores history-based activation. This overlay never records an unmoved piece as moved. Checkmate/pausing stops the transport as before.
- Select a piece to inspect its instrument and adjust gain, pitch, pan, decay, filters, reverb, and delay. The inspector follows its identity after moves and stays selected when the AI moves.
- Piece Params contains note/rest feedback and envelope/octave/gate knobs. Board Params changes the shared root/scale. Strudel contains transport/status above the code. In-game edits stay local to that match; save city kits through Creative.

See `GAME_MECHANICS.md` for the maintained behavior inventory, gesture limitations and state priorities.
- The code widget is generated from the same voice specifications used to build the Strudel patterns. The spectrogram reads the new audio output.

## Modules

- `reactions.ts` (v0.3.2): validated per-kit state/event rules, deterministic history ledger and reversible audio overlays shared by Creative and gameplay. Factory and legacy unedited kits receive the versioned 26-rule preset; authored rule sets are preserved. Event durations use plies; per-rule bar scheduling and tempo ramps are owned by the audio transport. See GAME_MECHANICS.md for triggers, scope, priorities and the simulation's differences from match termination.
- `harmony.ts`: named shared harmonic plans, resolved section centers, chord symbols and scale-derived triads. `voice-spec.ts` moves bass/melody with each center and turns sustain onsets into compact voice-led triads for moving plans; the static plan preserves authored voicings. Pulse voices, manual audition and unpitched samples remain unchanged. The monitor exposes the same resolved harmony used by audio. The base plan is saved in each kit and reactions can replace it reversibly.
- `manchester-kit.ts`: curated Manchester 1999 arrangement, 123 BPM / G Dorian, four banks, weighted 5:4 eighths and complementary motifs. `chicken-jazz-v1` adds 11 original synthetic one-shots (~300 KB) generated by `scripts/generate-jazz-samples.py`; no reference audio is bundled. `node scripts/export-manchester-kit.cjs` regenerates the portable JSON and Strudel score. Sample URLs in the score require this app's `/samples` directory on the serving origin.
- `team-mixer.ts`: two post-effects Web Audio buses with independent gain and three-band EQ. Match-only fine pitch changes the shared tempo and tuning; quartz lock restores loaded-kit BPM and normal tuning while preserving the prepared slider value. Reverse audio and scratching are not implemented.
- `voice-spec.ts` assigns loop voices to four Superdough effect orbits on desktop and two on constrained devices; temporary auditions keep isolated orbits. `runtime-session.ts` retains a shared orbit until its final loop voice leaves. Continuous performance forms use `pick` to query only the selected phase-preserving bank, while restarting forms use `pickRestart`.
- `model.ts`: stable piece identity reconstructed from legal move history, shared scale conversion, initial electronic instrument definitions.
- `runtime.ts`: compatible entry point. Implementations: `runtime-types.ts` (contracts), `voice-spec.ts` (resolved controls), `pattern-compiler.ts` (Strudel patterns), `code-export.ts` (score), `pattern-inspection.ts` (previews/validation/conversion), `strudel-loader.ts` (shared loading), `runtime-session.ts` (playback lifecycle). Internal modules import contracts directly, avoiding cycles through the facade.
- `sample-banks.ts`: source registry independent of chess roles and playback behavior; bank, asset, articulation and optional root-note tuning. Assets load only when needed and buffers are shared. The original CC0 `Chicken Electro · 01` bank ships with 13 small WAV files (~447 KB total), including a tuned bell. It is not a TR-909 recording bank. Regenerate with `python3 scripts/generate-samples.py`.
- `automation.ts`: bounded patterns per section and sine/ramp curves for gain, low-pass, pan, reverb and delay. Gain multiplies the base value; other automated controls replace their fixed values. Values are sampled at note attacks, not continuously inside an already sounding note.
- `grooves.ts`: shared named grooves with rhythm/accent lanes. Any instrument can reference any lane; notes remain in the instrument's phrase bank. Editing a lane changes every linked voice, while disabling one piece leaves the other lanes intact.
- `creative.ts` and `city-kits.ts`: schema v4, migrations, factory kit, import validation and browser-local city persistence. Source, behavior and chess role are independent: a king can play an unpitched kick and a pawn a tuned bell sequence.
- `random-kit.ts`: versioned seeded arrangements for every city, randomized roles and bounded parameters. This remains an experimental generator; factory defaults now come from styled-kits.ts.
- `monitor.ts` and `components/music-playback.tsx`: shared section/beat, notes/rests and resolved control values. Queries use the same compiled Strudel patterns as audio, aligned to the transport clock. Small subscribers and cached per-cycle queries avoid rerendering the editor on every tick.
- The selected voice's variation panels compile once per configuration and cache four-cycle preview windows. Saved variants remain visible while inactive; only the executing variant has a playhead. Actual timeline queries preserve alignment when phrases, grooves and automations have different bank sizes.
- `hooks/use-music.ts`: React state and controls. Piece parameter edits are keyed by identity; undo/redo restores board-derived activation and position while retaining manual edits.

## Checks

`npm run test:music` covers activation, audition rollback, captures, en passant, castling, history reconstruction, source independence, real Strudel groove/automation timing, timeline migration, sample files, city persistence, playback feedback and transport races. Pattern tests import the same `@strudel/web/dist/index.mjs` ESM bundle used by the browser; only browser event-listener globals are stubbed. `npx tsc --noEmit --incremental false` checks application types.

The comparative Düsseldorf preset timeline is `[0@4 1@4 2@4 1@4]/16`: A/B/C/B, four cycles each. The former `<0@4 1@4 2@4 1@4>/16` unintentionally held each section for 64 cycles. Imports repair that exact legacy factory string; custom timelines are preserved. Old kits retain their sources and masks; choose the factory button to audition the new unmasked arrangement.

## Deliberate scope of this prototype

The current editor combines synths, registered samples, phrases, grooves and automation through validated configuration; it does not evaluate arbitrary user JavaScript. A stopped transport restarts from the beginning when playback resumes. Editing or deactivating all loops while playing preserves its phase. Shared harmonic plans move section centers and generate diatonic triads with compact inversions; style-specific extensions, cadence preparation, continuous inter-note legato, user sample uploads and official kit publishing remain in MUSIC_ENGINE_PLAN.md. Network-free loading of the entire application has not yet been implemented. Musical quality and physical mobile performance still need listening/device validation.

Strudel references: [samples](https://strudel.cc/learn/samples/), [effects](https://strudel.cc/learn/effects/), [mini-notation](https://strudel.cc/learn/mini-notation/).

- `scales.ts`: catálogo comum de escalas em 12-TET, utilizado pela sessão e pelas reações.
- `transport.ts` / `reaction-queue.ts`: audio-time scheduling, analytic BPM ramps, per-rule pending changes and cancellation; React only displays clock state.
- `piano-roll.ts`: bounded note/duration schema for independent loops; the Creative editor converts finite source windows and preserves source text for restoration.

- `performance.ts`: per-instrument sections (beats, bank, presence, chromatic transpose, optional restart), with 24 blocks/512 beats limits. Fixed variants and game rules override the plan. Compilation reuses identical banks within a form.
- `kit-profiles/*.ts`: one editable score profile per city; each assigns 16 mirrored roles, four pattern banks, timbre, mix and per-section presence. `catalog.ts` registers them. `styled-kits.ts` composes 14 defaults and performs a revisioned, recoverable migration through `city-kits.ts`. Historical references/limits live in `MUSIC_STYLE_REFERENCES.md`.
- `scripts/export-mouth-breather.cjs`: extracts the supplied study's exact note timing using real Strudel and builds a six-piece preset with local synthetic timbres. The entire form, guitar/bass pitches, drum onsets and exported score are regression-tested.
- `piano-roll.ts` also stores optional per-note pitch envelopes and pan. Envelope time becomes canonical `pattack`; per-note values override instrument controls after automation. `pianoOnly` identifies scores composed directly as notes, without a textual restoration source.
- `components/info-tip.tsx`: hover/focus/touch help portalled above scrolling columns. Escape/outside press dismisses; pressing help does not edit the associated control.

- `roll-optimizer.ts`: finite event lanes shared by compiler/exporter; `manual-reverb-cache.ts`: bounded impulse reuse with isolated effect nodes. Measurements and rejected substitutions: `docs/CPU_OPTIMIZATION.md`.
